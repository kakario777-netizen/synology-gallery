# 시놀 갤러리

시놀로지 포토(Synology Photos)에 로그인해서 사진·동영상을 보는 안드로이드 갤러리 앱.
동기화·백업 없이 **보기 전용**.

## 기능
- 로그인: QuickConnect ID 또는 NAS 주소(DDNS·IP:포트) + 아이디/비밀번호, 2단계 인증(OTP), 자동 로그인
- 탭: 사진 / 앨범 / 태그 / 폴더 (켜기·끄기, 순서 변경, 좌우로 밀어 이동)
- 앱 잠금: 지문 우선 + 패턴
- 비슷한 사진 모으기 (묶는 정도 1~4단계), 앨범·태그 편집
- 강조색 선택 (빨강·검정·파랑·초록 등)
- 개인 공간 ↔ 공유 공간 전환
- 썸네일 격자: 두 손가락으로 열 개수 조절, 월별/일별 묶음, 동영상 길이 표시
- 사진 뷰어: 좌우 넘기기, 확대/축소, 정보, 슬라이드쇼
- 동영상 재생: 반복, 음소거, 화면 켜짐 유지
- 설정: 정렬(촬영일/파일명, 최신/오래된순), 종류(전체/사진/동영상), 썸네일·뷰어 화질, 캐시 비우기 등
